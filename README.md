# NEONPLAY · Página de descarga

Página pública para descargar **NEONPLAY**, la red social para quienes juegan en el celular (beta para Android, solo mayores de 18).

Se publica con GitHub Pages desde la rama `main`. La versión, la fecha, el tamaño y la huella SHA-256 del APK se leen en vivo
de la última beta publicada. El código de la app no está aquí.

Esta página se genera desde `Neonplay_Informacion/10_Pagina_Descarga/` del proyecto; los cambios se hacen allá y se copian aquí.
